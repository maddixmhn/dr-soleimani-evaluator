# دکتر سلیمانی | ارزیاب مستقل

پروژهٔ مستقل برای پایش و تحلیل عملکرد دانشگاه مجازی ایجنتیک فاران؛ ارائهٔ درسی برای «ارزیابی کارایی سیستم‌های کامپیوتری» به دکتر علی سلیمانی. تمام fixtureهای همراه ساختگی‌اند و ارزیاب به LMS/Paperclip وصل نیست.

## اجرای وب محلی

فایل‌ها را با یک وب‌سرور محلی سرو کنید تا service worker فعال شود. نمونه از دکمهٔ «نمایش دادهٔ نمونه» بارگذاری می‌شود. برای تبادل با پروژهٔ دانشگاه، JSON پالایش‌شدهٔ `faran-event-schema/1.0` را بارگذاری کنید.

## Android

نیازمند Node.js 20+، Android Studio، JDK و Android SDK سازگار است:

```sh
npm ci
npm run android:sync
```

APK debug را با Gradle wrapper در `android/` می‌توان ساخت. wrapper به دریافت توزیع Gradle نیاز دارد. فایل‌های `www/` تولیدی در Git نگهداری نمی‌شوند.

## ارزیابی

روش شاخص‌ها، خطاها، محدودیت پیش‌بینی و تصمیم انسانی در [docs/evaluation-method.md](docs/evaluation-method.md) آمده است. مقالهٔ درسی در [docs/ARTICLE.md](docs/ARTICLE.md) است. گزارش نمونه معیار عملکرد واقعی ایجنت یا آموزش نیست.
